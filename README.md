# Patience R. Hub

Lovable Build Prompt — Patience R. Hub Site

Brand Overview

Build a personal brand hub site for "Patience R." — tagline "Create. Solve. Automate. Inspire." Positioning: "I help ideas turn into impact." Patience is a solo entrepreneur/creator who builds smart solutions, digital tools, and resources across five core pillars. She is a one-woman operation — no team, no agency framing.

Reference image attached for the Home page hero — match the visual direction exactly: black background, cream/off-white body copy, gold/tan accent (#D4A574-ish), elegant script logo treatment for "Patience R.", thin gold underline accents, minimal line-icon set (sparkle, heart, lightning bolt, sunburst, target, lightbulb, envelope).

Design System

Palette: Black (#0A0A0A–#111111) primary background, warm cream (#F5EFE6-ish) for light sections, gold/tan (#D4A574-ish) for accents/CTAs/underlines, white/off-white text on dark sections, near-black text on cream sections.

Typography: Elegant serif or script display font for headlines and the logo (mimic the "Patience R." wordmark and "turn into impact" script accent), clean sans-serif for body copy and nav.

Icons: Thin-line/outline style only, no filled icons. Consistent stroke weight throughout.

Tone: Polished, warm, confident — not corporate-agency, not girly-template. Understated luxury feel.

Buttons: Solid gold/tan fill with black text for primary CTAs; text-link with icon for secondary CTAs (e.g. heart icon).

Site Navigation

Home | About Me | What I Do | Resources | Shop | Work With Me | Contact Plus a "Let's Connect" pill button top-right (dark outline, arrow icon).

Functional Notes

Stack: Lovable + Supabase (data/auth if needed) + Vercel (hosting) + Resend (email capture/ newsletter) + PayFast (any direct payment links, e.g. printables).

Newsletter signup in hero panel should POST to Resend.

All external product links (xoxasocial, Umnotho, Petal & Ring, PKD Ratsela books) open in new tab, clearly marked as external.

Fully responsive, mobile-first — the hero especially needs a clean mobile stacked layout (portrait image above or below headline, trust panel collapses into an accordion or stacked block).

No filler stock-photo icons — keep the thin-line icon set consistent across every page.
